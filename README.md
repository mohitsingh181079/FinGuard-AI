**Try it now:** https://fin-guard-ai.streamlit.app

### 🎯 Features
- ⚡ **Real-time Prediction** - Instant fraud risk analysis
- 🧠 **AI Powered** - Machine Learning model
- 🌆 **City Agnostic** - Works with any city name
- 🕒 **Time-based Analysis** - Considers transaction hour
- 🎨 **Modern UI** - Dark theme, responsive design

### 🛠️ Tech Stack
- **Frontend:** Streamlit
- **Backend:** Python
- **ML Model:** Scikit-learn / Pandas / NumPy
- **Deployment:** Streamlit Cloud
- **Version Control:** Git & GitHub
